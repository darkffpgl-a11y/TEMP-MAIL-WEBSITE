Data & Privacy

Only appearance and interface preferences are saved locally under tm_premium_prefs_v1, and the last working API route is remembered under tm_premium_transport_v1. No email content, tokens, or sensitive data is stored. Email storage and deletion depend entirely on the connected API provider (mail.tm / mail.gw). If the direct API is CORS-blocked, requests are automatically retried through built-in CORS relay proxies.
